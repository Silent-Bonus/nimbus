# Recipe Standardization

This folder tracks the UI and architecture cleanup for the recipe flow.

The current goal is to make recipe screens follow the same premium, consistent
patterns already used by the stronger self-care screens.

## Scope

- screen shell consistency
- typography migration
- shared header usage
- pill/filter consistency
- search field consistency
- recipe-specific service/type ownership

## Files

- [Recipe Standardization Plan](./recipe-standardization-plan.md)

## Outcome

The target state is:

- one typography system
- one header pattern
- one list-screen shell pattern
- recipe-specific code kept in recipe-specific files
- no visual drift between tools recipe screens and premium self-care screens
