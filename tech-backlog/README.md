## Tech Backlog

This folder holds technical notes, test inventories, and follow-up work that is not part of the shipped app code.

Current contents:
- `dev-commands.txt`: quick local commands used during development.
- `screen-standardization-notes.txt`: working notes and screen-level backlog observations.
- `code-quality-followups.txt`: code quality and architecture follow-ups.
- `testing-strategy.txt`: broader automation testing plan.
- `testing/`: module-specific testing audits and manual test sheets.
